🚀 SUPERADMIN API ENDPOINTS (Use from your admin panel)

1. GENERATE SITEMAP.XML → PRODUCTION
   POST /api/admin/sitemap/save-to-production
   
   ✓ Creates sitemap.xml at /www/wwwroot/marketmindai.com/sitemap.xml
   ✓ Includes: homepage, tools, blogs, categories, locations
   ✓ Updates automatically with latest content

2. GENERATE ROBOTS.TXT → PRODUCTION
   POST /api/admin/sitemap/save-robots-txt
   
   ✓ Creates robots.txt at /www/wwwroot/marketmindai.com/robots.txt
   ✓ Allows crawling, blocks admin areas
   ✓ Points to sitemap.xml

3. REGENERATE ALL PAGES → PRODUCTION
   POST /api/seo/regenerate-all
   
   ✓ Creates HTML pages for all tools at /tools/{slug}/
   ✓ Creates HTML pages for all blogs at /blogs/{slug}/
   ✓ Includes location-based pages
   ✓ Each page has unique SEO meta tags

4. CHECK GENERATION PROGRESS
   GET /api/seo/regenerate-progress/{task_id}
   
   ✓ Real-time progress tracking
   ✓ Shows tools/blogs processed
   ✓ Shows errors and warnings

5. GET GENERATION STATISTICS
   GET /api/seo/generation-stats
   
   ✓ Shows how many pages generated
   ✓ Shows build path location
   ✓ Shows last update time

6. GET BUILD PATH INFO
   GET /api/seo/build-path-info
   
   ✓ Confirms production path is active
   ✓ Shows /www/wwwroot/marketmindai.com/
   ✓ Verifies path exists and has files
