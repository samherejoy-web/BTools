## 🚀 Quick Start (3 Steps)

### Step 1: Upload to Server

```bash
# From your local machine
scp marketmindai-frontend-production.tar.gz your-user@your-server:~/
scp deploy-frontend.sh your-user@your-server:~/
```

### Step 2: Run Deployment Script

```bash
# On your server
ssh your-user@your-server
cd ~
sudo ./deploy-frontend.sh
```

### Step 3: Verify

```bash
# Test homepage
curl -I https://marketmindai.com

# Test API
curl https://marketmindai.com/api/health
```

**That's it!** Your frontend is deployed.

## 🐛 Common Issues & Solutions

### Issue: Blank Page
**Solution**: Check browser console for errors, verify `PUBLIC_URL` is correct

### Issue: API 404 Errors
**Solution**: Check backend is running, verify nginx/apache proxy config

### Issue: CORS Errors
**Solution**: Verify backend `.env` has `CORS_ORIGINS="https://marketmindai.com"`

### Issue: CSS Not Loading
**Solution**: Check file permissions (644 for files, 755 for directories)

**Full troubleshooting guide in `PRODUCTION_DEPLOYMENT_INSTRUCTIONS.md`**
